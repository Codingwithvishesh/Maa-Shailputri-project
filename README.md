# Navratri Day 1: Maa Shailputri Particle Assembly 🌸✨

An advanced cosmic particle assembly animation that gathers flying luminous particles into a high-definition portrait of **Maa Shailputri**, the first form of Navratri Durga.

---

## 📁 Included Files

1. **`particle_assembly.py`**:
   - Python script using OpenCV and NumPy.
   - Features **harmonic vortex curves**, **staggered departure waves**, **golden energy transitions**, and **vectorized rendering**.
   - Can also export to MP4 directly.

2. **`particle_assembly.html`**:
   - Interactive HTML5 Canvas web application (runs in Chrome, Edge, Safari, Firefox).
   - Features **real-time mouse repulsion forcefield**, **synthesized temple bell chimes**, **speed/duration sliders**, and a **custom image upload button**.

3. **`particle_assembly.mp4`**:
   - High-definition 10-second video rendered with 310 frames of cosmic vortex particle assembly.
   - Ready to share on WhatsApp Status, Instagram Reels, or YouTube Shorts.

4. **`shailputri.jpg`**:
   - Divine high-resolution portrait of Goddess Maa Shailputri seated on the sacred bull Nandi.

---

## 🚀 How to Run

### 1. In Browser (No Installation Needed)
Double-click `particle_assembly.html` to open it in your browser, or drag and drop any of your own photos to watch them assemble!

### 2. In Python (Desktop GUI Window)
Ensure you have `opencv-python` and `numpy` installed:
```bash
pip install opencv-python numpy
```

Run the animation:
```bash
python particle_assembly.py
```
*(Press `ESC` in the window to close)*

Export to a new video file:
```bash
python particle_assembly.py shailputri.jpg my_reel.mp4
```

### 3. Watch the Video
Open `particle_assembly.mp4` with any media player.
